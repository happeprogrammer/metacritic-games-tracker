О проекте

Это демонстрационный стенд, сделанный как тестовое задание на позицию AI Automation Engineer. Он не является коммерческим сервисом, а данные Metacritic принадлежат их владельцам и показаны здесь только для демонстрации.

Что делает сервис

Раз в час он заходит на Metacritic, берёт 20 игр, которые сегодня ещё не обрабатывал, и сохраняет о них информацию: название, обложку, платформы с оценками критиков и игроков, разработчика, описание, ссылку на видео. По отзывам нейросеть пишет короткое резюме: что нравится и не нравится, отдельно критикам и отдельно игрокам. Если игра уже есть в базе, данные обновляются.

Выбор игр. Первые 20 дня берутся из блока New Releases, дальше по странице из списка «все игры, новые». Новый день начинается заново.
Сбор. Карточка игры, оценки по каждой платформе, выборка отзывов критиков и игроков. Не чаще одного запроса в секунду.
Резюме. Нейросеть выделяет «нравится / не нравится» и аспекты игры. Каждый пункт подтверждается цитатой, которую код сверяет с отзывами.
Витрина. Список, фильтры, поиск, сортировка по рейтингу, карточка игры, похожие игры.
Монитор. Состояние воркеров, очередь, лимиты нейросетей, живой журнал и кнопка запуска.

Что посмотреть проверяющему

  1. Список игр: попробуйте поиск, фильтр по платформе, жанру и аспекту («где хвалят сюжет»), сортировку по оценке.
  2. Откройте карточку любой игры: оценки по платформам, динамика оценок, резюме с цитатами (нажмите на пункт, чтобы увидеть подтверждение), похожие игры.
  3. Монитор: статусы воркеров, очередь, состояние нейросетей и источника, живой журнал.
  4. На мониторе нажмите «Запустить сбор сейчас»: принудительный запуск (с паузой между нажатиями и суточным лимитом).

Допущения и ограничения

  • Нейросети используются только по бесплатным тарифам, поэтому число резюме в сутки ограничено. Игры с наибольшим числом отзывов обрабатываются первыми, у остальных стоит пометка «резюме в очереди».
  • «Разрыв критиков и игроков» — это разница двух оценок, а не доказательство накрутки.
  • Резюме строятся по выборке отзывов (до 40 каждого вида), а не по всем отзывам.
  • Метаскор критиков показан по шкале 0–100, оценка игроков по шкале 0–10.
  • Сервис работает на маленьком сервере с жёсткими лимитами памяти и процессора и временный: после проверки он будет удалён.

Как устроено внутри

Один небольшой процесс на Node.js без сторонних библиотек, база SQLite, страницы без фреймворков. Планировщик с учётом дня, устойчивая очередь задач, цепочка бесплатных провайдеров нейросетей с лимитами и запасными вариантами, проверка цитат против выдумок, вход по паролю, журнал действий. Подробности и код — в репозитории, ссылка на который приложена к письму.
